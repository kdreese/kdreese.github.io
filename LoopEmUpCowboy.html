Loop 'Em Up, Cowboy!

Game and Development Info

  • Genre:
    Survivor-like
  • Platform:
    PC (Windows, Linux, Mac, and browser)
  • Project Status:
    Originally created in 96 hours for the 2025 GMTK Game Jam. Released on Itch.io
  • Game Description:
    Loop 'Em Up, Cowboy! is an arcade-style shoot-em-up set in the old west. Grab enemies with your lasso and throw them at obstacles to defeat them.
  • Role:
    Gameplay Designer and Programmer
  • Tools Used:
    Godot, GitHub
  • Project Duration:
    July - August 2025
  • Team Size:
    3

Team Responsibilities and Lessons Learned

  • Designed and developed the enemy AI and spawn system
  • Implemented the player health system
  • Fleshed out design direction and created design document
  • Ran playtesting
  • Scoping appropriately helps the whole project go smoothly
    This was our first game jam project that we weren't rushing to get features in at the last minute. We decided on a simple premise early on, created a simple MVP checklist, and developed everything in a way that was easy to add to. Once we had the base MVP finished, it was easy to test it, and slowly add polish and new features that weren't going to break our game before release.
  • Sometimes less is more
    On top of helping with scope and crunch, the simpler footprint for this game made it more immediately understandable and approachable. We received a lot of feedback that it was fun switching back and forth between the combat styles of lassoing and bowling, and I believe the focus on that gameplay helped the game shine.
